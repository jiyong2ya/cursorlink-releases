# cursorlink

Windows PC 여러 대 (마스터 1 + 슬레이브 최대 2) 를 마우스 / 키보드 하나로 쓰는 프로그램.

```
[왼쪽 슬레이브] ← [마스터] → [오른쪽 슬레이브]
```

- **마스터**: 마우스 / 키보드가 꽂힌 PC (라이선스 키 필요)
- **슬레이브**: 마스터의 마우스 / 키보드로 조작되는 PC (키 필요 없음)

할 수 있는 것:

- **쓸어넘기기**: 마스터 화면 왼쪽 / 오른쪽 끝으로 마우스를 밀면 그쪽 슬레이브로 넘어감. 단축키로도 이동
- **미러**: 마스터 + 슬레이브를 동시에 조작 (같은 위치 클릭, 같은 키 입력)
- **클립보드 공유** (텍스트)
- 설치 없이 exe 하나. 드라이버 없음

## 다운로드

**[cursorlink.exe 받기 (최신 버전)](https://github.com/jiyong2ya/cursorlink-releases/releases/latest/download/cursorlink.exe)** · [모든 버전](https://github.com/jiyong2ya/cursorlink-releases/releases)

마스터와 슬레이브 모두 같은 파일을 씀.

## 설치

모든 PC 가 같은 공유기 (같은 네트워크) 에 있어야 함. **슬레이브부터** 하면 편함.

### 1. 슬레이브 PC (슬레이브마다)

1. 폴더를 하나 만들고 `cursorlink.exe` 를 넣고 실행 → 설정 창이 뜸
   - "Windows의 PC 보호" 창이 뜨면 "추가 정보" → "실행"
2. 역할: **슬레이브**
3. 비밀값: 아무 문자열 (16자 이상 권장). **모든 PC 에 똑같이** 넣어야 하니 적어 둘 것
4. "기타" 에서 **관리자 권한으로 실행** + **Windows 시작할 때 자동 실행** 체크 (권장)
5. "저장하고 시작" → Windows 방화벽 창이 뜨면 **허용**
6. 창 위쪽 **"이 PC 주소"** 에 나오는 **컴퓨터 이름** (예: `DESKTOP-AB12CD3`) 을 적어 둠 → 3단계에서 마스터에 넣음

슬레이브에는 마스터 주소를 넣는 칸이 없음. 비밀값만 같으면 마스터가 찾아와서 연결함.

### 2. 라이선스 받기 (마스터 PC)

1. 마스터 PC 에서 `cursorlink.exe` 실행 → 설정 창 → 역할: **마스터**
2. "라이선스" 의 **기기 코드** 옆 "복사" → 배포자에게 보냄
3. 받은 키 (`CL1.` 로 시작) 를 "라이선스 키" 칸에 붙여 넣기 → 바로 아래에 "정상" 이 뜨면 됨

Windows 를 다시 설치하면 기기 코드가 바뀌어서 키를 다시 받아야 함.

### 3. 마스터 설정

1. 비밀값: 슬레이브와 **똑같이**
2. "슬레이브" 칸에 1단계에서 적어 둔 **슬레이브의 컴퓨터 이름** 을 넣음
   - 마스터 화면 **왼쪽** 에 둔 PC → "왼쪽" 칸, **오른쪽** 에 둔 PC → "오른쪽" 칸. 없는 쪽은 비워 둠
3. 칸마다 **"연결 확인"** → "연결 OK (비밀값 일치)" 가 나오면 성공 (안 되면 아래 [문제 해결](#문제-해결))
4. "저장하고 시작" → 방화벽 창이 뜨면 허용

이제 마스터 화면 끝으로 마우스를 밀면 옆 PC 로 넘어감. 설정을 바꿀 땐 트레이 아이콘 우클릭 → "설정..."
(이미 켜져 있을 때 `cursorlink.exe` 를 다시 실행해도 설정 창이 뜸).

### 슬레이브: 관리자 권한 / UAC

- **관리자 권한으로 실행** 을 켜 두면 설치 프로그램, 작업 관리자 같은 관리자 권한 창에서도 조작됨
  (직접 실행할 때 UAC 확인 한 번, 자동 실행일 땐 확인 없이)
- UAC 확인창 (예 / 아니요) 과 잠금화면은 Windows 가 막아서 마스터로 조작할 수 없음 (뜨면 마스터로 돌아옴).
  마스터로 누르고 싶으면 그 슬레이브의 UAC 를 "알리지 않음" 으로 (설정 창 "기타" → "UAC 설정 열기").
  대신 프로그램이 묻지 않고 관리자 권한을 얻게 됨.

## 기본 단축키

| 키 | 동작 |
|---|---|
| 넘패드 `/` | 왼쪽 슬레이브로 이동 (미러 중엔 왼쪽 슬레이브를 미러에서 빼기 / 넣기) |
| 넘패드 `-` | 오른쪽 슬레이브로 이동 (미러 중엔 오른쪽 슬레이브를 미러에서 빼기 / 넣기) |
| 넘패드 `.` | 마스터로 복귀 (슬레이브 쓰는 중에만) |
| 넘패드 `*` | 미러 토글 |
| 넘패드 `+` | 쓸어넘기기 양쪽 토글 |
| Ctrl + 넘패드 `/` | 쓸어넘기기 왼쪽 토글 |
| Ctrl + 넘패드 `-` | 쓸어넘기기 오른쪽 토글 |
| Ctrl + Alt + K | cursorlink 전체 토글 |

설정 창 "단축키" 에서 칸을 누르고 원하는 키를 누르면 바뀜 (Esc = 취소).
단축키로 정한 키는 원래 입력이 안 됨 (예: 넘패드 `/` 로 `/` 입력 불가).
쓸어넘기기를 꺼도 단축키 이동과 마스터로 복귀 (슬레이브 화면에서 마스터 쪽 끝으로 밀기) 는 됨.

## 문제 해결

**"연결 확인" 결과별로**

| 나오는 말 | 할 것 |
|---|---|
| 연결 OK (비밀값 일치) | 정상 |
| 켜져 있음. 이미 마스터와 연결돼 있어서… | 정상 (마스터가 이미 붙어 있는 상태) |
| … 를 찾지 못함 | 컴퓨터 이름 오타 확인. 그 PC 가 켜져 있고 같은 네트워크인지 |
| 응답 없음 / 연결 안 됨 | 그 PC 에서 cursorlink 가 켜져 있는지 (트레이 아이콘), 방화벽에서 허용했는지 |
| 비밀값이 다름 | 그 슬레이브 설정 창의 비밀값을 마스터와 똑같이 |

**방화벽을 허용했는데도 연결이 안 됨**
그 PC 의 네트워크가 "공용" 이면 막힐 수 있음 → Windows 설정 → 네트워크 및 인터넷 →
연결 중인 이더넷 / Wi-Fi → 네트워크 프로필을 **"개인"** 으로.

**컴퓨터 이름 대신 IP 를 넣어도 되나**
됨. 다만 IP 는 재부팅하면 바뀔 수 있어서 이름을 권장.
이름이 알아보기 어려우면 그 PC 의 Windows 설정 → 시스템 → 정보 → "이 PC의 이름 바꾸기"
(재부팅 후 마스터 설정에 새 이름을 넣음).

**슬레이브가 절전 / 재부팅했음**
다시 켜지면 마스터가 알아서 다시 연결함 (슬레이브에서 "자동 실행" 을 켜 두면 됨).

**단축키가 안 먹음**
- 업데이트할 때 예전 cursorlink 를 끄지 않고 새 것을 켜면 두 개가 될 수 있음
  → 작업 관리자에서 cursorlink 를 모두 끄고 하나만 실행
- 다른 프로그램이 같은 키를 쓰는 중일 수 있음 → 설정 창에서 다른 키로

**그 밖에**
트레이 아이콘 우클릭 → "로그 보기" 내용을 배포자에게 보내 주세요.

## 업데이트 / 지우기

- **업데이트**: 트레이 아이콘 우클릭 → 종료 → 새 `cursorlink.exe` 로 바꿔 넣고 실행. 설정은 그대로.
- **지우기**: 트레이 아이콘 우클릭 → 종료 → 폴더 삭제.
  Windows 시작 프로그램에 cursorlink 항목이 남지만 exe 가 없으면 아무것도 안 켜짐
  (지우려면 작업 관리자 → 시작 프로그램에서 "사용 안 함").
